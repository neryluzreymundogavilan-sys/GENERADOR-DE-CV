# Generador Web de Currículum (CV) — Dossier Documental

Aplicación web interactiva para la creación de Currículum Vitae en formato A4 y anexado de dossier documental (certificados en imagen y documentos Word `.docx`) con sistema de registro, sincronización en la nube entre dispositivos y aprobación por administradora.

## Funcionalidades Principales
- **Registro y Solicitud de Acceso Multi-Dispositivo:** Los estudiantes y egresados se registran desde cualquier celular o computadora y sus solicitudes quedan guardadas en la nube para aparecer automáticamente en el **Panel de la Administradora**.
- **Panel de Administradora (`admin2026`):** Permite visualizar en tiempo real todas las solicitudes enviadas desde distintos celulares, aceptarlas, rechazarlas o eliminarlas, además de revisar los envíos de CV.
- **Selectores Inteligentes por Carrera:** Perfil profesional, experiencia laboral, formación académica, habilidades y proyectos adaptados a la carrera seleccionada.
- **Dossier Documental A4:** Carga de constancias en imagen o documentos Word (`.docx`) anexados automáticamente como hojas A4 adicionales listos para exportar a PDF.
